Features a web app
can't do.

These three things only work because Waypoint lives inside Chrome. A web app doesn't have access to any of them.

🖱️

Right-click → Save

Select any code on Stack Overflow, GitHub, or MDN. Right-click. Saved to Waypoint instantly. The context menu API is extension-only.

Pro
🔔

Desktop Notifications

Native OS alerts for PR reviews and CI failures. Polls every 15 minutes. Works even when Chrome is in the background. Web apps can't send OS-level notifications without an open tab.

Pro
☁️

Cross-Device Sync

Uses Chrome's built-in chrome.storage.sync API. Your snippets and settings appear on every machine where you're logged into Chrome. No backend, no latency.

FAQ

Questions.

How is Waypoint different from daily.dev? +

daily.dev is a news feed — it replaces your new tab with articles to scroll. Waypoint is a productivity tool. No content, no algorithm, no feed. Just the tools you actually use.

Is my GitHub token safe? +

Your token never leaves your machine. It's stored in Chrome's local encrypted storage — the same API Chrome uses for saved passwords. Waypoint has no backend and sends your credentials nowhere.

Does it work on Edge, Brave, or Arc? +

Yes, all Chromium-based browsers work. Firefox support is on the roadmap but not available yet.

What happens to my data if I uninstall? +

Your data is stored locally. Go to Settings → Export before uninstalling to download a JSON backup of all snippets, bookmarks, and environments. You can reimport it anytime.

How does Pro licensing work? +

After purchase you receive a license key. Paste it into Waypoint's Settings → Subscription. Pro activates immediately, no account required. The key works across all your Chrome installs.
