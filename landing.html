Chrome native

Features a web app
can't do.

These three things only work because Waypoint lives inside Chrome. A web app doesn't have access to any of them.

Extension only

Right-click → Save

Select any code on Stack Overflow, GitHub, or MDN. Right-click. Saved to Waypoint. The context menu API is extension-only.

Extension only

Desktop Notifications

Native OS alerts for PR reviews and CI failures. Polls GitHub every 15 minutes. Works even when Chrome is in the background. Web apps can't send OS-level notifications without an open tab.

Extension only

Cross-Device Sync

Uses Chrome's built-in chrome.storage.sync API. Your snippets and settings follow you to every machine where you're signed in to Chrome, with no Waypoint backend.

FAQ

Questions.

How is Waypoint different from daily.dev? +

daily.dev is a news feed: it replaces your new tab with articles to scroll. Waypoint is a productivity tool. No content, no algorithm, no feed. Just the tools you actually use every day.

Is my GitHub token safe? +

Your token is stored locally in Chrome's extension storage and is only sent to GitHub, to fetch your pull requests and CI status. Waypoint has no backend of its own. Like any browser-stored secret, anything that can read your Chrome profile could read it, so use a token with the narrowest scopes you need.

Does it work on Edge, Brave, or Arc? +

Waypoint is built and tested in Chrome. Other Chromium-based browsers that load Chrome extensions should work, but have not been tested. There is no Firefox version.

What happens to my data if I uninstall? +

Your data is stored locally. Go to Settings → Export before uninstalling to download a JSON backup of all snippets, bookmarks, and environments. You can reimport it at any time.

Is it on the Chrome Web Store? +

Not yet. Waypoint is a personal open-source project. Clone the repo, build it, then load the dist/ folder through chrome://extensions with Developer mode on. The README has the exact steps.
